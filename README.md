Lofi Music Player – study and focus with a Pomodoro timer and chill vibes.

**Adding new music or vibe videos:**  
- If you run the app with **`npm start`**: just drop files into `music/` or `vibes/` and refresh.  
- If you open `index.html` directly or deploy as a static site: run **`npm run update-files`** after adding files so `file-list.json` is updated.
